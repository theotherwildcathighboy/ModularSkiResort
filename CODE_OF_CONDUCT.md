# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in its
issues, pull requests, the Paradox forum thread and the Discord thread.

In short: be kind and patient, assume good intent, keep feedback about the work, and leave out harassment, insults and
personal attacks of any kind. Bug reports from players who are new to modding are welcome.

To report a problem, send the maintainer a private message on GitHub or on the Paradox forum. Reports are read in private.
The maintainer may edit or remove comments, and block accounts, that break these rules.
