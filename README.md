# Modular Ski Resort — a Cities: Skylines II mod

Build a ski resort in CS2:

- Draw fixed-grip and detachable chairlifts, gondolas and an aerial tram with one lift tool. The tool gives numbered
  towers with automatic height and a cable that the chairs and cabins ride.
- Start a ski area with a Welcome Sign. Place standalone lodges, a Ski School and patrol buildings.
- Paint runs. The game's own snow simulation keeps a run open at 3 ft of snow. Snow guns are active from two
  months before winter to one month after. A run melts when the snow goes.
- Or outline a mountainside: the experimental Resort Planner proposes linked runs, cat tracks and lifts, and builds them.

Attractiveness, tourism and a resort economy (tickets, passes, lessons, lodge spend) react to runs, lifts and season.
The mod needs the base game only.

Started 2026-08-03. A working chairlift beta took 5 days. The docs site's Timeline page tells the rest.

## Layout

| Path | What |
|---|---|
| `mod/SkiResortMod/` | The code mod (C#, net48, game-referenced). `dotnet build` auto-deploys. |
| `assets/blender/` | Deterministic Blender/Python generators for every mesh + texture. |
| `assets/import/` | Generator OUTPUT staged for Editor import (gitignored — regenerable). |
| `gamedata-mirror/` | Version-controlled backup of our hand-made game-side prefabs (tools/sync-gamedata.ps1). |
| `docs-site/` | The player docs site (Astro Starlight), published with GitHub Pages. |
| `locale/` | `en-US.json`, the translation template (generated by `tools/export-locale.js`). |
| `tests/` | Headless test hosts for the pure rules (`dotnet run --project tests/<Name>/<Name>.csproj -c Release`). |
| `tools/` | preflight.ps1, validate_prefab.ps1, jxr2png.ps1, sync-gamedata.ps1. |
| `release/` | Paradox Mods staging: listing copy, credits, changelog, screenshots. |
