The mod is a one-person project built with Claude (Anthropic) as the working partner.

## Authorship

The code, the Blender asset generators, the documentation and this site were written by Claude under the author's direction.

- **Author:** sets direction, makes every design verdict, does every Editor import and every in-game test, reviews the previews before anything is exported.
- **Claude:** reads the decompiled game, designs and writes the code and generators, runs the checks, keeps the decision ledger.

## Models

All work ran through Claude Code in the Claude desktop app, with one linked session per task.

| Model | Role |
|---|---|
| Claude Fable 5.1 | Lead architect and orchestrator: design, correctness, the decision ledger. |
| Claude Opus 5.5 | Plan-first and research rounds, new code paths. |
| Claude Sonnet 5.5 | Prepared build rounds with a written brief. |

- **Earlier phases:** August to early October 2026 ran on earlier Claude models.
- **Other AI:** one document of tower-planner defaults (real-world span table and design phases) was drafted with Google Gemini and reviewed before use ([Timeline](/timeline/), Oct 19).

## Process

- **Preview gate:** every asset is previewed and approved before export. Nothing is imported without a verdict.
- **Decision ledger:** each decision is a dated entry with its cause. The [Timeline](/timeline/) is built from it.
- **Reviews:** design and code reviews run as adversarial sessions separate from the ones that built the work.
- **Checks:** test hosts and build gates are listed on [Asset Pipeline](/asset-pipeline/#gates).
- **Evidence:** a claim about engine behaviour needs the decompiled game or a field test. The ledger was corrected twice when a test disagreed.

## Assets

- **Origin:** meshes and textures come from the project's own Blender generators and from CC0 tiling sets (ambientCG).
- **Third-party models:** credited with their licences on [Credits and Licences](/credits/).
- **Vanilla props:** referenced by the game's own ids; no vanilla asset is copied.
