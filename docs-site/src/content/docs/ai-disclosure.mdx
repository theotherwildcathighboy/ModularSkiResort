The mod is a one-person project built with Claude (Anthropic) as the working partner.

## Authorship

The code, the Blender asset generators, the documentation and this site were written by Claude under the author's direction.

- **Author:** sets direction, makes every design verdict, reviews the previews before anything is exported, judges every build in the game and does the final release check by hand.
- **Claude:** reads the decompiled game, designs and writes the code and generators, runs the checks, keeps the written decision record. Since October 31, 2026, Claude also drives test passes in the running game through a test bridge, and does Editor imports after the author's preview verdict. Before that, the author did every import and every in-game test.

## Process

- **Preview gate:** every asset is previewed and approved before export. Nothing is imported without a verdict.
- **Decision record:** each decision is a dated entry with its cause. The [Timeline](/timeline/) is built from it.
- **Reviews:** design and code reviews run as adversarial sessions separate from the ones that built the work.
- **Checks:** automated tests and build checks, summarized on [Asset Pipeline](/asset-pipeline/#review-loop).
- **Evidence:** a claim about engine behavior needs the decompiled game or a field test. The record was corrected twice when a test disagreed.

## Assets

- **Origin:** meshes and textures come from the project's own Blender generators and from CC0 tiling sets (ambientCG).
- **Third-party models:** credited with their licenses on [Credits and Licenses](/credits/).
- **Vanilla props:** referenced by the game's own ids. No vanilla asset is copied.
