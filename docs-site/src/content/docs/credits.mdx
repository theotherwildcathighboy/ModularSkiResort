## Inspiration

- **Modular Golf Course Pack** (Paradox Mods ID 144768): the modular-recreation concept that inspired this
  project's architecture.
- **Meapy, CS2-TourismOverhaul**: the tourism and attraction framework this mod integrates with; studied for
  compatibility and design reference. Optional.
- **Yenyang, Recolor**: the asset colour convention (channel masks, light-albedo regions) follows the standard
  their mod established; hosted towers are recolourable through its painter. Optional.
- **klyte45, Write Everywhere** (Paradox Mods 92908): optional. If installed, the Welcome Sign shows the ski
  area's name through a layout file we ship, and the lodge and school name boards become writable. Nothing of
  Write Everywhere is included and the mod never requires it.
- **tomkpunkt, ParkManager** (Paradox Mods 161179, GPL-3.0): studied as a research reference for programmatic net
  and object creation, ordered cleanup and Gameface UI patterns. No code copied, no runtime dependency.
- **krzychu124, Scene Explorer**: indispensable for live ECS debugging during development.
- **CitiesSkylinesModding community**: the agents-plugins toolchain and documentation.

## References

- **Arapahoe Basin's original Pallavicini lift** (a Yan double): this mod's fixed-grip hardware is a nostalgia tribute.
- **Lift Blog** (liftblog.com, Peter Landsman): the lift-engineering reference behind the lift family. Tower,
  terminal and tram designs were studied against its photo essays (notably the Peak 2 Peak Gondola and the
  Jackson Hole Aerial Tram pages). Photos were used as reference only; nothing from the site is redistributed.

## Lettering

The sign sets (lodge, school, patrol and gate boards) carry text rasterised at build time from typefaces installed
on the build machine: Bookman Old Style Bold for the resort-identity boards, Franklin Gothic Demi Cond for the
utility boards. Only the rendered textures ship; no font file is included or required. The lift boards are
lettered with Blender's built-in font.
