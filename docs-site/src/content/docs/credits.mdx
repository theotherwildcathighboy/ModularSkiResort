## Inspiration

- **Modular Golf Course Pack** by joergeske: the modular-recreation concept that inspired this
  project's architecture.
- **Meapy, CS2-TourismOverhaul**: the tourism and attraction framework this mod integrates with; studied for
  compatibility and design reference. Optional.
- **tomkpunkt, ParkManager** (Paradox Mods 161179, GPL-3.0): studied as a research reference for programmatic net
  and object creation, ordered cleanup and Gameface UI patterns. No code copied, no runtime dependency.
- **Yenyang, Recolor**: the color convention the stations follow (channel masks, light-albedo regions). Optional; its
  painter recolors line towers.
- **klyte45, Write Everywhere**: optional. If installed, the Welcome Sign shows the ski area's name, and the lodge and
  school name boards become writable. Nothing of it is included and the mod never requires it.
- **Lift Blog (liftblog.com, Peter Landsman)**: the lift-engineering reference behind the lift family. Photos were
  studied as reference only; nothing from the site is redistributed.
- **krzychu124, Scene Explorer**: live ECS debugging during development.
- **CitiesSkylinesModding community**: the agents-plugins toolchain and documentation.

## Asset Inspirations

Each asset follows a real lift or building. They are places that matter to the author.

| Asset | Real place |
|---|---|
| A-frame lodge | The A-frame lodge at Arapahoe Basin, Colorado |
| Fixed-grip chairlift | The Pallavicini lift at Arapahoe Basin, Colorado |
| Detachable quad | The Collins lift at Alta, Utah |
| Gondola | Loosely the Aspen gondola, made more generic |
| Aerial tram | The Jackson Hole Aerial Tram, Wyoming |
| Grand lodge | The Peak 7 lodge at Breckenridge, Colorado |
| Chalet hut | A peak lodge at Courchevel, France |
| Ski School | The kids' ski school at Palisades Tahoe, California |
| Small patrol hut | The Lady Morgan ski patrol shack at Deer Valley, Park City, Utah |
| Large patrol hut | The patrol building at Song Mountain, Finger Lakes, New York |

## Lettering

The sign sets (lodge, Ski School, patrol and gate boards) carry text rasterized at build time from system typefaces: Bookman Old Style Bold for the resort-identity boards, Franklin Gothic Demi Cond for the
utility boards. Only the rendered textures ship; no font file is included or required. The lift boards are
lettered with Blender's built-in font.
