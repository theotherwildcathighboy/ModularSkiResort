## Drawing

Hub **Runs** tab > type > area tool, drawn from the lift top downhill.

- **Linking:** a run within the ski area radius (**5 km** by default) of a Welcome Sign is linked to that ski area when you draw it. It stays linked if the radius changes later. Option **Link runs the moment they are drawn**, default on.
- **Feedback:** slope heat-map (gray flat, green, blue, black, red double black), contour lines, tooltip with rating, hardest unavoidable pitch, length, vertical drop.

## Rating

Rating = slope of the **hardest unavoidable pitch**: the crux of the easiest line from run top to run bottom. A flat runout cannot hide a steep pitch, and one corner on a bank cannot make a double black.

| Slope of that pitch | Rating | Worth (before size and type) |
|---|---|---|
| under 6 % | Flat (unrated) | 0 |
| 6 to 25 % | Green circle | 6 |
| 25 to 40 % | Blue square | 12 |
| 40 to 60 % | Black diamond | 20 |
| 60 % and over | Double black diamond | 28 |

- **Cannot be rated:** outline too large, too thin or without terrain. Worth **3**.
- **New run:** counts **0** until rated.
- **Reshaped run:** keeps its last rating during re-rating.
- **Size factor:** bigger runs are worth more, with diminishing returns: **1** at 2 ha, about **1.4** at 8 ha, the cap **2** at about 56 ha. Under 1 ha it falls in proportion to the area. Worked values: [Attraction Formula](/reference/attraction/#size-factor).

## Run Features

One **Run** tile draws every run. A row under it sets the next run's features: **Groomed** (On or Off), **Snow guns** and **Lights** (Off, or the distance between them). Both need Groomed. A built run changes them in the Runs view, for the run selected in the list. The hub's run list names each run's features (*Groomed, snowmaking, lit*).

<Tabs>
  <TabItem label="Natural">
    <Icon name="run-natural" alt="Natural run icon" />
    **Groomed off.** **Surface:** none drawn (visible on the **piste map**). Opens on natural snow only.
    **Value:** green ×**0.5**, blue ×**0.75**, black ×**1**. **Build fee:** 500 + 250 per ha. **Upkeep:** none.
  </TabItem>
  <TabItem label="Groomed">
    <Icon name="run-groomed" alt="Groomed run icon" />
    **Surface:** groomed snow. **Value:** full when open.
    **Build fee:** 2,000 + 1,000 per ha. **Upkeep:** 150 per ha per month while snow-covered, also while its snow guns are stopped because the snow is deep enough.
  </TabItem>
  <TabItem label="Snow guns">
    <Icon name="run-snowmaking" alt="Snow guns icon" />
    **Adds:** snow guns (lances, fan guns, hydrants) where the air is cold enough: the run opens earlier and stays open longer.
    **Build fee:** +2,000 + 3,000 per ha. **Upkeep:** +350 per ha per month where the guns make snow.
  </TabItem>
  <TabItem label="Lights">
    <Icon name="run-night" alt="Lights icon" />
    **Adds:** floodlights. **Value:** ×**1.25** of groomed.
    **Build fee:** +2,000 + 3,000 per ha. **Upkeep:** +300 per ha per month while snow-covered.
  </TabItem>
  <TabItem label="Cat track">
    <Icon name="run-cat-track" alt="Cat track icon" />
    **Role:** link across the hill. It carries lift service to the runs it meets lower down (see [Lift Service](#lift-service)). Always rated **green**. It counts **a quarter** of a run its size in score and capacity. **Pricing:** as groomed. **Upkeep:** 500 per ha of plan area per month while its guns can run. None while its snow guns are set to Off.
    **Snow guns:** guns and hydrants on one side of the ribbon. The decal stays the look: they add no snow. It opens like a run with snow guns, at up to the snowmaking margin above freezing. With its snow guns set to Off, it makes no snow. Snow already made stays until it melts.
    **Slope limit:** built with the cat track tool below, which grades the ground to stay under **25 %**, so a cat track is always green. Crosses other runs without changing them.
  </TabItem>
</Tabs>

- **Paid once:** a feature's fee is charged the first time it is on, by the run's area. Turning it off refunds nothing. Turning it on again is free. Changing a distance is free.
- **Groomed on a built run:** the run's surface is redrawn, so it may flash for a moment, as the game does with any area that changes type. Everything else carries over: its name, its ski area, its snow guns and lights, its trees.
- **Names:** a new run gets a trail name from a list of **200** that fits it. Examples: a black run a *Chute* or a *Wall*, a green a *Meadow* or a *Lane*, a run through trees a *Glade*, a cat track a *Road* or a *Way*. A run near the top or the bottom of its ski area may be *Upper …* or *Lower …*. No two runs share a name while one is free. After that, the name is *Run N*. The name comes once the run is rated, stays through reshaping and reloads, and a rename wins.

Reshaping a run: no extra cost.

## Cat Track Tool

One action: lay out the track. **Enter** cuts and fills the ground so it never climbs steeper than the grade you set. Then it builds the cat track on the graded strip.

- **Open:** hub **Runs** tab > **Cat track**, or **Ctrl+Shift+K**.
- **Use:** click points up the hill. Drag a point to move it. Right click steps back one point (with no point left it closes the tool). **Enter** builds. **Esc** closes. Right click and **Esc** never remove a track that is built.
- **Delete mode:** hub **Runs** tab > **Delete cat tracks**, or **Ctrl+Shift+D** while the tool is open. Hover a track to outline it, click it once to arm it (red), click again to delete it. A click elsewhere disarms it. Right click or **Esc** leaves Delete mode without deleting. With the mode off, a click on an existing cat track starts a new track there (a branch).
- **Delete from the list:** the trash button on the cat track's row in the hub's **Runs** list: click it, then click again within 4 seconds.
- **After a delete:** the ground stays as graded and the fee is not refunded, like the bulldozer on a run. The bulldozer itself cannot pick a cat track.
- **Defaults:** max grade **25 %**, width **20 m**, cut slope **1:1.5**, fill slope **1:2**. Grading is free, like vanilla terraforming. The track pays the cat track fee.
- **Switchbacks:** legs closer than the track width are refused: spread them apart or make the track narrower.
- **Mode:** With *Cat track: constant grade* off, the track follows the ground and moves as little earth as the max grade allows. On: one even slope from end to end.
- **Too steep:** a path that cannot stay under the max grade is refused, with the missing length in meters. Add a switchback.
- **Crossing runs:** a cat track crosses groomed and natural runs, with or without snow guns or lights, and keeps their difficulty. Inside a run there is no flat bench. The run's ground keeps its own slope and is graded at most **2 m** along the track, fading out toward the run's edges. Outside, the grading fades in over the **15 m** before the run. If a crossed run would change its difficulty, the tool grades less inside it (down to none), or refuses the crossing. Where 2 m is not enough the plan turns red: cross it more level, not down the fall line. Trees in the 15 m before a run are cleared with the rest of the corridor. A run the track only runs beside is left alone and the track keeps its full width. Two cat tracks cannot overlap.
- **Terrain:** trees in the corridor are removed (not inside a crossed run). The run catalog rates again after the terrain changes. A track whose graded strip reaches under a building or station, into water, or within **6 m** of a lift line is refused.
- **Plan cat tracks before lifts:** grading changes the ground, so a cat track can never pass under a lift that is already built. Build the track first, then draw the lift over it.
- **Options:** Options > Modular Ski Resort > Main > Runs. Max grade **5 to 25 %**, width **8 to 32 m**, cut **1 to 3**, fill **1 to 4**.

## Resort Planner (Experimental)

Outline a region and the planner proposes lifts and a set of linked runs around them. You review and change the plan. You build the proposed lifts yourself on the marked spots. You build the runs together.

<Aside type="caution" title="Experimental">
The Resort Planner is new and may change. It is off by default: turn it on in Options > Modular Ski Resort > Main > Runs > **Resort Planner (experimental)**. While it is off, the tool cannot open and its hub button is grayed with the reason.

**Limits:** it builds runs only. You build the lifts it proposes with the lift tool. On steep ground expect mostly black runs and few greens. Roads, buildings and lift stations inside the outline are not avoided. **Undo** and **Undo trees** end when the tool closes.
</Aside>

- **Open:** hub **Runs** tab > **Resort Planner (experimental)**, or **Ctrl+Shift+Q**. While it is open, the Runs tab shows every control as a button.
- **Outline:** click the corners of the region (up to **9 km²**, about 3 x 3 km), then the first corner again to close the outline and scan it. Drag a corner to move it, click an edge to add a corner, and right click to reopen the outline. The tooltip shows the size against the limit and the vertical. Outline open slope: roads, buildings and lift stations inside the outline are not avoided, and runs can be planned across them.
- **Around a lift:** with no corner placed, click the station of a lift you built: the outline becomes **150 m** on each side of its line plus **400 m** below its base station. Right click clears those corners together.
- **Site verdict:** one plain line says how steep the outlined ground is, as an average grade: gentle (under 25 %), steep (25 to 44 %), very steep (45 to 57 %) or steeper than any real ski area (58 % and up). It shows while you outline, in the tooltip and the hub, and updates after the scan.
- **Scan:** closing the outline, **Scan** or **Enter**. The scan runs in the background, so the game keeps running, and the hub shows its progress (*Scanning the region: 40 %*). Right click stops it. Moving a corner or changing a knob during a scan starts it again. **Build**, **Undo** and the tree buttons wait until it ends.
- **Refused:** a scan that finds nothing says why. *Mostly cliff*: no run reaches the bottom. *Too narrow*: a run needs open slope about 70 m across, clear of other areas. *No run fits*: try another shape or another mix. Others: too flat, too little vertical, mostly taken by other areas or unowned land.
- **The plan on the map:** each proposed lift is a dashed line with its towers and hatched station spots, colored by its way home, with a label (*P2: Detachable, 1.3 km, 540 m up, reaches 7 run(s)*). Lifts you already built in or next to the outline join the plan, with a white ring at their stations. The runs are grouped in **pods**, the runs one lift serves: a ring in the pod's terrain color, labeled *Pod B: Intermediate*. Runs show in piste-map colors, natural runs dashed.
- **The plan in the hub:** *Planned: 6 pod(s), 3 lift(s) proposed, 12.4 km of runs*, what the mountain's ground gives by color, then one row per lift (length, rise, runs it reaches, its way home and its pod's runs by color), then the pods no lift serves (*no lift planned*). A lift you built reads *Existing lift*.
- **Way home:** for each lift, the easiest run from its top back to a lift or the base: *Green way home*, *Blue way home*, *Black only*, *Double Black only*, or *No way down on skis: ride the lift down*.
- **Pick:** click a run to leave it out (gray) or take it back. Click a proposed lift's line, a built lift's station ring, a pod's ring, or its row in the hub. This leaves out the lift and its pod's runs (or the pod's runs), or takes them back. Picking plans nothing again.
- **Knobs:** **Lifts** (auto, or 1 to 9, and changing it plans again), **Way home** (green at the base and blue above by default, or green, or blue: the easiest run each lift top should offer), **Mix** (Balanced, Beginner, Expert, As the slope allows), **How many** (Few, Normal, Many, and the count scales with the region), **Features** (every run groomed by default, and the options *Leave black runs natural*, *Snowmaking near the base* for green runs that reach the base, *Light the two lowest* for up to two base runs, blue or easier, which also get snow guns), **Shuffle** for another layout of the same region.
- **Totals:** runs kept, the mix against its target, the total fee, and skiers a day once a lift serves them.
- **Build:** **Build** or **Enter**. Refused when the city cannot pay the total. Only the runs are built: they are linked and pay like runs you draw. A run the game refuses turns red and is left out. The rest are built.
- **Lifts:** the proposals stay proposals. Build each one with the lift tool: place the stations on the marked spots, then draw the line. Until a lift serves them, its runs count as backcountry (see [Lift Service](#lift-service)).
- **Wait:** the runs are built a few at a time so the game keeps running smoothly, with progress in the hub and the tooltip (*Building runs 4 / 11*). A large region can take a few seconds to a minute. **Stop** or right click stops after the runs in progress. What is built so far stays, and **Undo** removes it. Closing the tool also stops the build. What is built stays, without Undo.
- **Undo:** the hub's **Undo** removes the whole build and refunds exactly what it cost. Right click never removes built runs.
- **Warnings:** no lift fits the region, lift tops with no way down on skis, a run that ends where nothing continues, a lift top with no green way down, a run over water, runs that will be renumbered, runs in more than one ski area, no Welcome Sign nearby, a mix the slope cannot give, and the game's checks being off (Anarchy).
- **Trees:** **Tree filler** fills the outlined region with trees around the runs, up to a tree line. The tree line starts where the wild trees nearby stop. Move it 10 or 50 m at a time. Pick **Conifer** (default), **Deciduous**, **Palm**, **All trees** or a single species, and a density. **Plant** (or **Enter**) plants them a few thousand at a time until the region is full (*Planting trees 2,400 / 9,000*). A large region can take a few seconds to a minute. **Stop** (in place of Plant) or right click stops after the trees in progress. What is planted stays. **Undo trees** removes them. Filler trees count as wild trees: a run drawn over them later can clear them.
- **Undo ends on close:** **Undo** and **Undo trees** work until the Resort Planner closes. After that, built runs and planted trees stay. The bulldozer removes them one at a time and refunds no run fee.
- **Scan never ends:** see [Troubleshooting](/guides/troubleshooting/#common-cases).

## Snow Conditions

Snow is measured per run from the game's snow simulation.

- **Open:** at least **91 cm** of snow on **60 %** of the run. One bar for every run: natural or made, every rating.
- **Patchy:** between open and closed. Counts part of its value.
- **Closed:** an open run stays open while **30 cm** of snow covers **40 %** of it, then closes. A closed run opens again at **91 cm**.
- **Snow guns:** runs and cat tracks with snow guns on, where air temperature is at most **3.3 °C** above freezing (option *Snowmaking margin*). Higher margin: longer season, higher snowmaking bill.
- **Edge props:** guns, hydrants and floodlights stand along a run's edge at a set distance, however its outline was drawn: Off or **20** to **200 m**, per run, in the Runs view for the run selected in the list. A new run starts with the values of the row under the Run tile. A cat track starts with snow guns at **60 m** and lights Off. Snow guns Off: no guns, no made snow, no snowmaking upkeep (snow already made stays until it melts). Lights Off: no lights, no lighting upkeep. On a cat track the lights change only the look and the bill: **300** per ha of its plan area per month in its snow season, guns on or off. Each one is a separate object you can bulldoze. It stays gone until the outline or a value changes.
- **Gun depth:** the guns start when the run falls under **91 cm** and stop at **96 cm**, so the run stays open between restarts.
- **Gun season:** from **2 months before winter to 1 month after**, which is October 1 to April 1 when winter is December to February. There are no guns, no bill and no plume outside it. Where the game's own season reads Winter the guns run, and where it reads Summer they do not, whatever the date.
- **Cat tracks:** the snow under the track is measured like a natural run's, plus the snow its guns made. Made snow lasts through a warm spell as long as on the best-kept run, up to **72** game hours (**36** in spring, none above **10 °C**), then melts as fast as a run's snow does (about **6** game hours at **1 °C**, under **1** at **7 °C**), so a cat track closes last. A save keeps it.
- **Powder day:** fresh snow in the last 24 hours. More locals go skiing. See [Passes and Lessons](/guides/passes-and-lessons/).
- **Units:** the docs are metric. The in-game hub shows snow depth in the unit setting you chose in the game's options.
- **Estimated snow:** after a save load, or for a new sign, snow is estimated from the day's temperature. Marked **≈**.
- **No open run:** ski area counts as summer sightseeing. Lodges and lifts count at a reduced share. After one game hour with no open run, chairlifts and gondolas stop. The aerial tram keeps running as sightseeing.

<Aside type="note" title="Snow Gating Off">
Option **Snow & season gating** off: every run counts as open all year. Upkeep is paid only while grooming or snow guns run, so a warm map with gating off has **0** upkeep.
</Aside>

## Lift Service

Runs need lifts: a run reaches full value only while a lift serves it. See [Lifts](/guides/lifts/) for building one.

- **Served:** a complete, powered lift reaches the run top (the highest point of the outline). An unpowered, unfinished or missing-section lift serves nothing.
  - **Chairlift and gondola:** the lift line passes within **150 m** of the run top, and the run top is at most **15 m** above the top station.
  - **Aerial tram:** the run top is within **300 m** of the top terminal. The tram serves around its terminals only, not along the line.
- **Linked runs:** a run is served too when skiers can get onto it downhill from a served run in the same ski area. The two outlines must come within **25 m** of each other or overlap, and at least **30 m** of the run (or a third of its drop, if less) must lie below the junction. A run that only touches a served run at its own bottom is not served. Service never flows uphill: a run joined part way down passes service on only below that point. A chain of linked runs is served from one lift.
- **Cat tracks:** skiers get on a cat track where it meets a served run and ride it either way, as long as it never takes them more than **3 m** above where they got on. Runs the track meets on the way are served by the same downhill rule. A long cat track across the mountain serves only the runs it meets below where skiers get on.
- **Backcountry:** no lift serves the run. Counts **40 %** of a served run (option *Backcountry run value*).
- **Ski patrol:** raises nearby black backcountry runs to at least **70 %**. See [Lodges, Ski School and Patrol](/guides/lodges-school-patrol/).

## Glades

Tree tool: plans trees on and around runs. Hover a run, click.

- **Toggle:** **Ctrl+Shift+G**.
- **Tree density:** **Shift+G** steps **1** (clears the run) to **8** (thick forest).
- **Mode:** **Alt+G** switches run interior / tree line along the edge.
- **Rebinding:** all three keys in Options.
- **Cat tracks:** the Tree tool plans ski runs only. A cat track's top is cleared of trees when it is built.

## Piste Map

Hub Runs view switch **Piste map**: draws every run on the ground in difficulty colors.

- **Natural runs:** dashed.
- **Too flat:** gray.
- **Cannot be rated:** orange.
