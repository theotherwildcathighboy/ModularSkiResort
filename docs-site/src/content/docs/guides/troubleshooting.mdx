First source: hub **problem band** (fact line, tooltip with cost). Second source: the mod log, for a silent hub or
a hub line that points to the log.

## Problem Lines

| Line | Cause and fix |
|---|---|
| *More than 5 km from every Welcome Sign* | Place a Welcome Sign nearby. Unlinked runs and lifts score **0**. |
| *No lodge* | Build one near the sign from the Buildings tab. |
| *All lodges are switched off* / *Lodges switched off: N* | A lodge counts only while it is not set to Inactive in its own info panel. Clear that setting on one. |
| *Lodge is not at a road* / *Welcome Sign is not at a road* | Deck side (lodge) or front (sign) must touch a road. |
| *Welcome Sign at 74 %: …* | Sign efficiency below **100 %**. Causes: staff, power, water, sewage, garbage, budget. Every cause costing **5 %** or more is listed. |
| *No lift yet* / *Runs unconnected to a lift: N* | Run counts less until a running lift reaches its top: within **150 m** of the line, at most **15 m** above the top station. |
| *Lift X has no power* | Connect a low-voltage line to the base station. Maintenance is still charged. |
| *Runs that cannot be rated: N* | Outline too large, too thin, or without terrain. |
| *Runs too flat to score: N* | Flat run adds **0**. Draw on steeper ground. |
| *Many ski-day guests with a car never arrive* | Fewer guests are sent until more arrive. Add parking and roads. |
| *No parking near the lodge* | No car spaces within **300 m** of the lodge. |
| *Lodge is far from the runs* | Ski-day guests target lodges within **800 m** of runs or lift stations only. |
| *Ski school has no green run* | Ski School adds to score only while a green run counts. |

Snow facts: status line, and the Mountain section of the Attraction view.

## Log File

- **Folder:** `%CSII_USERDATAPATH%\Logs`.
- **Name:** `SkiResortMod.Mod.log`.
- **Line format:** `Tag [topic] message`.
- **Errors:** lines starting with `!!!`. Search for these first.

<Aside type="caution" title="Wording Changes">
Tags below exist in the current build. The text after each tag is paraphrased and may change between versions.
Problem reports: include the lines around any `!!!`.
</Aside>

## Log Tags

| Tag | Content |
|---|---|
| `!!!` anything | An error. Includes `UI module present: False` (hub front end did not load). |
| `PrefabCatalog [arm]` | Once per city load. Lists every expected prefab as **found** or **missing**. Missing = asset not installed; reinstall the mod. |
| `Lift [power]` | Lifts without electricity at the base station. |
| `Lifts [state]` | Lift state change: complete, unfinished, missing a section, chairs stopped. |
| `Towers [nodes]` / `Towers [summary]` | Tower placement along a line. Use for floating towers or a section that will not place. |
| `Snow [open]` / `Snow [measure]` | Run opened or closed, with the snow reading. |
| `Tickets [gate]` | Ticket gate open or closed, with reason (for example no open run, sign not running). |
| `Tickets [cost]` | Lift ticket money booked. |
| `SkiDays [idle]` | No ski area exists; nothing sent. |
| `SkiDays [day]` | Daily tally: sent, reached a lodge. |
| `Lodge [road]` | Road edge that satisfied each lodge's access. |
| `Catalog [rate]` | Run rated, with band. |
| `Hub [items]` | Hub build tiles disagree with the prefabs (price drift warning). |

Tickets missing from the Economy panel: check the log first, then [Economy](/guides/economy-panel/).

## Common Cases

- **Run never opens.** Status line shows *snow measured* or *estimated*. Open requires **3 ft (91 cm)** of snow on **60 %** of the run. Fixes: raise *Snowmaking margin*; build as Snowmaking (guns run October to March only); on a map without winter, turn off **Snow & season gating**.
- **Chairs stopped.** Hub: *Lift X: chairs not moving*. The lift still counts. Log: `Lifts [state]`, `Lift [power]`.
- **Hub button missing.** Options > Modular Ski Resort > Main > Ski Resort hub. The panel is always in the Universal Mod Panel.
- **DLL and UI version mismatch notice.** Reinstall the mod. Building works; resort statistics stay hidden until both halves match.
