## Features

<CardGrid>
  <Card title="Lifts" icon="rocket">
    Fixed-grip and detachable chairlifts, gondolas and an aerial tram. Tower height follows the terrain,
    the cable sags, carriers ride it.
  </Card>
  <Card title="Runs" icon="star">
    Run outline rated green to double black from its slope. Snow comes from the game's own simulation;
    snow guns extend the season where it is cold enough.
  </Card>
  <Card title="Lodges, School, Patrol" icon="heart">
    **5** lodge tiers, a ski school and patrol huts, all upgrades of the Welcome Sign (the ski area).
    Guests and locals ski; the city's tourism responds.
  </Card>
  <Card title="Hub" icon="open-book">
    One panel: score, runs, lifts, guests, finances, history and every building tool.
  </Card>
</CardGrid>

## Install

1. Subscribe to **Modular Ski Resort** on Paradox Mods. *(The link goes here at the first upload.)*
2. **Dependencies:** none. Lifts, runs and the economy work on the base game.
3. **Access:** **Ski Resort** tab under Parks & Recreation, or the Ski Resort button at the top left.

<Aside type="note" title="Compatibility">
Tourism Overhaul, Realistic Workplaces and Households and Write Everywhere are detected, never required.
See [Credits and Licences](/credits/).
</Aside>
