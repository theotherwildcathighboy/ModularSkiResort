Per ski area **attraction score**, **0** to **200**, shown in the hub Attraction view. Scale: large park about **10**,
tourist attraction **50**, landmark **120**. The game converts the score to tourists.

## Equation

Score formula and its inputs.

```text
score = min( 200 , efficiency × ( lodge base + K × √S ) )

S     = ( runs + lifts + Ski School ) × variety × vertical
```

- **K:** option *Attraction scale*, default **4**. All runs open, full efficiency: small ski area about **50**, medium about **95**, large about **160**.
- **Square root:** doubling runs and lifts does not double the score. The game squares each building's attraction score when counting tourists. So tourists scale in proportion to ski area size.
- **Cap:** **200**.
- **Hub:** receipt rows per term. The full equation is in the section header tooltip.

## Lodge Base

The best lodge contributes its **base**. Every other lodge contributes its **extra**. Extras are capped at **24**.

| Lodge | Base | Extra |
|---|---|---|
| Mountain Hut | 16 | 4 |
| A-Frame Day Lodge | 20 | 4 |
| Chalet Lodge | 30 | 8 |
| Swanky Summit Lodge | 40 | 12 |
| Swanky Grand Lodge | 40 | 12 |

- **No run counts (summer):** lodge base ×**0.5** for Hut, A-frame, Chalet and Summit, ×**0.6** for Grand. A cat track alone does not end it.
- **Summer with a working lift top station within 300 m, or a lift-served run within 100 m:** Hut **75 %**, Summit **100 %**.

## Run Value

Each run adds:

```text
run value = difficulty × size × type × lift × open
```

| Factor | Values |
|---|---|
| **Difficulty** | Green **6**, blue **12**, black **20**, double black **28**. Flat **0**. Cannot be rated **3**. Pending **0**. |
| **Size** | `1 + 0.3 × ln(area ÷ 2 ha)`, at most **2**. Below 1 ha, scales down in proportion to the area. See [Size Factor](#size-factor). |
| **Type** | Groomed and snowmaking **1**. Night **1.25**. Natural: green **0.5**, blue **0.75**, black and double black **1**. |
| **Lift** | **1** if a running lift reaches the top. Otherwise *Backcountry run value* (default **40 %**). Patrolled run: at least **70 %**. |
| **Open** | Open **1**. Closed **0**. Patchy: partial. |

Snow moves the score: a closed run adds **0**. The receipt shows both the actual and the all-open sum.

### Size Factor

Bigger runs are worth more, with diminishing returns. Each doubling of the area adds only about **0.21**. A run of
2 ha is the reference (**1**). The cap of **2** needs about 56 ha.

| Area | Size factor |
|---|---|
| 0.25 ha | 0.20 |
| 0.5 ha | 0.40 |
| 1 ha | 0.79 |
| **2 ha** | **1.00** |
| 4 ha | 1.21 |
| 8 ha | 1.42 |
| 10 ha | 1.48 |
| 20 ha | 1.69 |
| 40 ha | 1.90 |
| 56 ha and up | 2.00 |

Under 1 ha the factor drops in a straight line to zero, so a tiny run is worth almost nothing.

## Lifts

Each complete, powered lift adds its type's **score value**.

| Fixed-grip | Detachable | Gondola | Aerial tram |
|---|---|---|---|
| 6 | 15 | 25 | 30 |

- **No run counts:** chairlifts and gondolas ×**0.25**.
- **Summer:** fixed-grip, detachable and gondola ×**0.25**, tram ×**1**.

## Ski School

**+12** while a green run counts. Otherwise **0**. The hub names the cause.

## Variety

**×1.15** while a green, a blue and a black (or harder) run all count. Otherwise **×1**.

## Vertical

Drop from the lowest run bottom to the highest run top, among counting runs.

```text
vertical factor = 1 + clamp( vertical meters ÷ 600 , 0 , 1 )
```

**×1** at 0 m. **×2** at 600 m or more.

## Efficiency

Welcome Sign efficiency as in its info panel: staff, power, water, sewage, garbage, budget and more.

- **Value used:** the day's average, at most **100 %**.
- **Effect:** multiplies the whole score.
- **Hub:** names every cause costing **5 %** or more.

## Tourist Draw

The score is the ski area's attraction score in the game's tourist formula.

- **Lodge info panels:** show **0** (the ski area carries the score).
- **Game counting:** each building's score squared. The hub shows this ski area's **share of the city's tourist draw**.
- **Effect:** the share sets how many tourists come to the city. Their destination is unaffected.
