## Running Cost

- **Billing:** full upkeep every month, including without power.
- **Reduction:** ×**0.25** while the lift is unfinished or its ski area has no open run. The tram keeps running with no open run and pays ×**0.5** then.

## Score Value

Added by a complete, powered lift.

- **Winter:** table value.
- **No run counts (summer):** the share row of the table. Chairlifts and gondolas ×**0.25**, the tram in full.

## Station Names

Format: type and end. *Fixed-Grip Chairlift: Base Station*, *Gondola: Top Station*, *Aerial Tram: Base Terminal*.

## Capacity

Design figure in skiers per hour, shown in the hub.

- **Tooltip:** lists seats per carrier and line speed.
- **Trip:** base to top at line speed, at 1× game speed.
- **Riders:** skier models are not shown on screen.

## Summer

A ski area with no open run for one game hour stops its chairlifts and gondolas. Only the tram keeps running, as sightseeing. What each then pays: [Running Cost](#running-cost).
