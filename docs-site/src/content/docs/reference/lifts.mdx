## Running Cost

- **Billing:** full amount every month, including without power.
- **Reduction:** ×**0.25** while the lift is unfinished or its ski area has no open run.

## Score Value

Added by a complete, powered lift.

- **Winter:** table value.
- **No run counts:** chairlifts ×**0.25**, gondolas ×**0.75**.
- **Summer:** share row of the table. The tram is the best summer attraction.

## Station Names

Format: type and end. *Fixed-Grip Chairlift: Base Station*, *Gondola: Top Station*, *Aerial Tram: Base Terminal*.

## Capacity

Design figure in skiers per hour, shown in the hub.

- **Tooltip:** lists seats per carrier and line speed.
- **Trip:** base to top at line speed, at 1× game speed.
- **Riders:** not simulated.

## Tram Operation

Shuttle: two cabins travel back and forth and dwell at each terminal.
